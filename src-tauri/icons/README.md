# Tauri icons

`icon.png` / `icon.ico` are **placeholder** icons generated for CI builds (a
simple cyan-ring mark used by the current shell). Replace
them with real Phira+ brand assets before release.

Tauri needs, per platform:
- Windows: `icon.ico` (multi-size; our placeholder is a 256×256 PNG-in-ICO).
- Android: mipmap PNGs — generated by `tauri icon <source.png>`.
- macOS (future): `icon.icns`.

Regenerate the full set from a square source PNG:
```sh
npx @tauri-apps/cli icon path/to/source-1024.png
```
